🐛 Common-Error Decoder

Symptom: nan in gradient → Likely Cause: Division by zero in numerical derivative or log(0). → Fix: Add \(\epsilon = 10^{-8}\) or use central difference.

Symptom: inf or Loss exploding → Likely Cause: Learning rate \(\alpha\) too large (overshooting curvature). → Fix: Reduce \(\alpha\) by 10x.

Symptom: Flat Loss (No Learning) → Likely Cause: Sigmoid saturation (vanishing gradient). → Fix: Use ReLU or normalize features.

Symptom: Gradient-Check Mismatch (> 1e-4) → Likely Cause: Dropped inner chain-rule factor. → Fix: Re-derive chain rule term-by-term.

SEGMENT 1

What a Slope Is, and Why a Curve Doesn't Have One

On a straight line \(y = mx + c\), slope is constant everywhere. On a curve like \(y = x^2\), steepness changes at every single point.

\[\text{Derivative for } f(x) = x^2: \quad \frac{df}{dx} = 2x\] \[\text{At } x=0 \implies 0, \quad \text{At } x=3 \implies 6, \quad \text{At } x=-3 \implies -6\]
SEGMENT 14 — CHAPTER 1 BRIDGE

Deriving OLS Normal Equations

Objective: \(E(\beta) = (y - X\beta)^\top (y - X\beta)\)

1. Expand: \(E(\beta) = y^\top y - 2\beta^\top X^\top y + \beta^\top X^\top X \beta\)

2. Differentiate wrt \(\beta\): \(\nabla_\beta E = -2X^\top y + 2X^\top X \beta\)

3. Set to zero: \(2X^\top X \beta = 2X^\top y \implies \mathbf{\hat{\beta} = (X^\top X)^{-1} X^\top y}\)
