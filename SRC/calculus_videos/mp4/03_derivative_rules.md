# Video 3 — Core derivative rules

Rules let us differentiate useful expressions without returning to the limit definition every time.

A constant has derivative zero. The power rule says the derivative of x to the n is n times x to the n minus 1. A constant multiplier stays in front. For sums, differentiate each term.

For f(x)=3x²−4x+7, the derivative is 6x−4. Notice that the constant 7 disappears because it never changes.

These rules are the algebraic engine behind gradients in linear models and neural networks.
